# 🚦 Smart Traffic Control System using Ultrasonic Sensors and FPGA

## 📌 Overview
This project implements an FPGA-based intelligent traffic monitoring and control system using dual ultrasonic sensors and Verilog HDL.

The system continuously measures object distance using ultrasonic sensors and dynamically analyzes traffic density on two sides. Based on the detected vehicle proximity, the system indicates the side with higher traffic density using LED comparison logic.

---

## 🛠 Technologies Used
- FPGA
- Verilog HDL
- Ultrasonic Sensors
- Xilinx Vivado
- Finite State Machine (FSM)
- Embedded Systems

---

## ✨ Features
- Real-time distance measurement using ultrasonic sensors
- Dual sensor traffic density comparison
- FPGA-based traffic monitoring logic
- LED indication based on vehicle proximity
- FSM-based ultrasonic sensor control
- Automated trigger and echo measurement

---

## 📂 Project Modules
- Ultrasonic Sensor Module
- Sensor Controller
- Dual Ultrasonic Comparison System
- FSM Control Logic
- Counter and Timing Logic

---

## ⚙ Working Principle
The ultrasonic sensors continuously transmit trigger pulses and measure echo response time to calculate distance. The FPGA processes sensor data and compares traffic density between two lanes. The side detecting closer vehicles is indicated using LEDs for intelligent traffic monitoring.
